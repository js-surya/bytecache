# ByteCatch batch 2 — plan

Owner request (2026-10-19): Face ID lock, API keys + change password, Markdown preview, widgets,
scan code from photos/camera, auto title & tags, quick-capture buttons. Same rules as v1: TDD for
logic, iPhone + iPad + Mac parity (OS limits listed), commit per feature, install each build on the
main iPhone simulator. Ledger: `.superpowers/sdd/2026-10-18-bytecatch/progress.md` ("Batch 2" lines).

## B1 Markdown preview
- `MarkdownDocument.parse(_:) -> [MarkdownBlock]` (headings 1–6, paragraphs, bullet/numbered/task lists,
  quotes, fenced code, rules). Inline formatting via `AttributedString(markdown:)` inline-only.
- Fragment card shows **Preview | Source** for `markdown` fragments; preview default.

## B2 App lock (Face ID / Touch ID / Optic ID / passcode)
- `AppLockModel`: enabled, timeout (Immediately, 1 min, 5 min, 15 min, 1 h); locks on launch and when
  returning after the timeout; `LocalAuthentication` `.deviceOwnerAuthentication` (falls back to passcode).
- Privacy cover while locked and in the app switcher. Share extension and intents are not locked
  (capture must stay one-step); widgets hide content while lock is on.
- `NSFaceIDUsageDescription`.

## B3 API keys + change password
- `GET/POST/DELETE /api/keys` (token auth only; create returns the key once), `POST /api/auth/change-password`
  `{currentPassword,newPassword}` (needs `allowPasswordChanges`).
- Settings → Account → API Keys / Change Password. API-key sessions see "Sign in with a password to manage keys".
- A new key is shown once with Copy; the app never stores it.

## B4 Widgets
- One WidgetKit extension (iOS + macOS): **Pinned Snippets** and **Recent Snippets**; small/medium/large,
  plus Lock Screen rectangular/inline on iOS.
- App writes `WidgetSnapshot` (JSON in the App Group) after refreshes; reloads timelines. No network in widget.
- Tap row → `bytecatch://snippet/<id>`; Copy button → `CopySnippetIntent` (interactive widget).
- App lock on → widgets show "Locked" instead of content.

## B5 Quick capture
- `CaptureClipboardIntent` (opens app) → capture sheet with clipboard text (`bytecatch://capture/clipboard`).
- Control Center / Lock Screen control (`ControlWidgetButton`, iOS 18+, macOS 26+) in the widget extension;
  App Shortcut "Save Clipboard to ByteCatch" for the Action Button and Siri.

## B6 Scan code
- iPhone/iPad: live camera with VisionKit `DataScannerViewController` (text, highlighting) and photo picker.
  Mac: choose image / paste image / drop image (no live camera API on macOS).
- Vision `VNRecognizeTextRequest` (accurate, language correction off); `OCRLayout.reconstruct` rebuilds lines and
  indentation from bounding boxes. Result opens the capture sheet (language detection runs as usual).
- `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription` not needed with PhotosPicker.

## B7 Auto title & tags
- `SnippetSuggester` protocol; `AppleIntelligenceSuggester` (FoundationModels, iOS/macOS 26+, on-device,
  `@Generable` title/description/categories). Unavailable → feature hidden.
- Capture sheet + editor: "Suggest" (sparkles) fills empty fields; auto-run on capture when the title is
  only the default. Settings toggle "Suggest Titles & Tags" (on).
