# ByteCatch batch 3 — plan

Owner request (2026-10-19): implement suggestions 4–13. Same rules: TDD for logic, iPhone/iPad/Mac parity,
commit per feature, install each build on the main iPhone simulator. Ledger lines start "Batch 3".

| # | Feature | Key decisions |
|---|---|---|
| 4 | Secret detector | `SecretScanner` (on-device regexes: AWS keys, GitHub/GitLab/Slack/Stripe/OpenAI/Google tokens, JWTs, private-key blocks, `password=`-style assignments, high-entropy strings next to secret-ish names). Capture sheet + editor show a warning banner with **Replace with {{SECRET}}**; saving still allowed. |
| 11 | Most used | `UsageTracker` (App Group defaults, per server + snippet id) counts copies from every copy path. Sidebar/Library "Most Used" list + sort option. Device-only. |
| 7 | Public snippets | Public toggle in detail + context menu (full PUT keeps everything). "Public" library section browsing `GET /api/public/snippets` (read-only; copy/save allowed). |
| 6 | Share links | `POST /api/share {snippetId, requiresAuth, expiresIn(seconds)}`, `GET /api/share/snippet/:id`, `DELETE /api/share/:id`. URL `<server>/s/<shareId>`. Sheet: create (expiry presets, require sign-in), copy, QR code (CoreImage), revoke. Password logins only (ByteStash rejects API keys here). |
| 10 | Bulk actions | Select mode in lists: pin/unpin, favorite, add/remove category, recycle, restore/delete in Recycle Bin. Category changes use full PUT per snippet. |
| 12 | Explain | `SnippetExplainer` on Apple Intelligence (iOS/macOS 26), "Explain" in detail → sheet with plain-language explanation; hidden when unavailable. |
| 9 | Backup | Export all snippets: ZIP of files (same naming as Save; zipped with `NSFileCoordinator .forUploading`) and a JSON backup (`ByteCatchBackup` v1). Import JSON from Settings. |
| 8 | Import | GitHub Gist URL (`api.github.com/gists/<id>`), VS Code `.code-snippets`/JSON, and code files/folders → preview list → create snippets (language detection on). |
| 5 | Offline save queue | `CaptureQueue` (App Group JSON) for captures/new snippets when offline (app, share extension, intents); retried on launch/foreground/connectivity; banner shows pending count. |
| 13 | Code editor | Live syntax colouring while typing (highlight.js grammars, same as the viewer — not tree-sitter: no tree-sitter editor exists for both UIKit and AppKit SwiftUI apps), line numbers, auto-indent, auto-closing brackets, matching-bracket highlight, find & replace (`findNavigator`). iOS/macOS 26 rich `TextEditor`; plain editor on older systems. |
